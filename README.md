## Contenido

- [`biblioexpress/`](biblioexpress/) — proyecto completo de práctica basado en el
  final anterior ("BiblioExpress"). API REST con Spring Boot, todo en memoria.
  Incluye:
  - código fuente comentado en español explicando cada decisión
  - [`README.md`](biblioexpress/README.md) — cómo correrlo y dónde está cada concepto
  - [`GUIA-DEFENSA-ORAL.md`](biblioexpress/GUIA-DEFENSA-ORAL.md) — preguntas del profe y respuestas

## Cómo correr el proyecto

```bash
cd biblioexpress
mvn spring-boot:run
```

Requiere Java 17+ y Maven (ya instalados en esta máquina).
